# 原站材质、局部地面与林带的原生修复

适用：已有建筑场景被指出黑面、缺地、车棚异常，或需在不破坏原场景的前提下补充植被。方法来自长丰迭代；案例规模、网格编号和精度不是其他项目的默认参数。先读 `native-verification.md` 的候选冻结与受限画面约束。本参考不是自动执行脚本。

## 从最新否决建立审计范围

将反馈时间码映射到实际镜头、源帧、相机与对象。用户要求全面排查时，不能只检查旧的几个故障点：枚举获准范围内全部非树对象、有效材质槽、实际材质实例、纹理引用和网格的源/渲染表示，分别记录已读、待判断、不可观测及错误。

源模型和 RenderData 都要核对。引擎默认材质、Nanite 上下文、透明混合及不可用的 mip 接口只是审计项，不能一律称为缺陷，也不能因枚举成功宣称全场景零风险。审计不扩大 NoAI 几何、纹理或像素读取权限。

## “复用原站材质”以实际加载器为准

1. 在授权范围确认网站实际加载的模型版本、加载代码与缓存身份；在本地证据中绑定字节摘要。页面相似不证明当前文件相同，公开案例不携带内部 URL、文件路径或这些项目摘要。
2. 核对加载器究竟采用 metallic-roughness、specular-glossiness、unlit 或转换分支。同一文件可同时带多条材质描述；扩展存在不等于运行时使用它。不要把未实现的 SG 回退值当作网站的白色，也不要机械按 MR 改写真正采用 SG 的其他网站。
3. 迁入实际使用的 base color、金属度、粗糙度、alpha、双面、UV/纹理变换和采样设置；分别处理颜色纹理与线性数据。只转码获准的纹理，比较解码 RGBA 与导出结果，记录不支持项；字节等价不证明原生外观已一致。
4. 用独立材质/网格副本限定修改槽位，保留明确的用户例外，不覆盖共享源材质。网站不投影、曝光或后处理配置不自动成为引擎的照明要求；保留当前已授权光照基线，除非任务明确要求匹配它。

## 黑面先分因，再做最小修复

按同相机、同曝光的对照定位材质、法线/背剔、真实缺面、重复共面、流送或阴影。若诊断画面含受限素材，先通过本次完整受限集合、全部 Primitive 与逐帧实际隐藏门，才能查看；新增植被后必须重新枚举，不能继续用旧隐藏数量。

- **法线**：在独立派生网格中定向纠错；比较位置、拓扑、有效 UV、材质分配及实际渲染数据。不要同时用几何翻面和补偿 shader 抵消，或为了消警告重铺全部 UV。派生路径若关闭 Nanite/重算切线，明确记录该改变、兼容限制与待测性能，不暗称等价无损。
- **缺地**：对黑区主体选多个射线/命中点，不只点边缘草地尖端；记录 owner、源面、原高程与连通上表面。只恢复已确认的原始边界、坐标和 UV，排除旧补片重叠。source 命中、派生导出与 fresh readback 应形成对应；整块 unhide、共面矩形盖板和抬高薄片不是默认修法。
- **车棚**：顶面、底面、侧边、立柱和底座分别验看；顶面正常不证明棚下或背面正常。暗阴影与指定黑饰面改白是不同任务，不全局增亮、关影或改白光伏和玻璃。
- **矩形阴影/水面异常**：隔离诊断中隐藏对象可能留下虚拟阴影缓存。先在独立运行做缓存重置、反射、动态阴影和对象可见性等有记录的对照，不把某个开关有效直接外推成所有黑区的原因。只改变诊断缓存时明确其临时性；正式进程重新检查真实对象/阴影状态，不带着“关阴影”绕过缺陷。

同机位去敏 probe 只证明其可见范围。修复后还需相邻机位、近远及连续帧回归；完整场景始终按许可进入人工审看。

## 林带是场景编辑，不是视频贴层

先确认真实可种区域、道路/建筑/水面/设施禁区与素材许可。要求保留原树时，冻结原实例与全部变换，仅在独立候选追加。只复用获准变体；不要因为要更自然就扩大资产种类或读取权限。

使用可重建的种子和簇状疏密，按实际资产包围盒/获准元数据约束树冠、根部接地、尺度和朝向；自然程度仍由人工判断。中心不在路上不代表树冠不侵路。检查真实地面支持、道路退距、建筑和设施间距、主体视线带以及每个实际镜头的连续路线；采样或 AABB 仅是已声明的保守近似，不冒称精确碰撞。

保存后独立回读原树未变、新树集合及变换。正式输出逐帧观测真实渲染世界的原/新增实例与可见状态，而非只读离线计划。植被影响阴影、反射、遮挡或背景时，重新评估全部镜头，通常需要全镜头新原生输出；不能后期贴树、复用旧镜头再称全片已更新。

## 保存、渲染与入剪的三次闭合

- **保存闭合**：复制地图模板后重新捕获完整对象状态。引擎复制可能重置已有组件的碰撞等属性；与父候选严格比较，按契约恢复，保留失败模板。不能因为变化是引擎造成就放宽保护门。独立 fresh readback 再查源/渲染数据、材质引用、原对象和新实例。
- **渲染闭合**：冻结新候选的源码、配置、Content 与全部镜头；probe/full 使用相同闭包。正式任务检查实际相机、动态对象、树实例、输出帧及退出状态；构建回执后退出崩溃不等于干净完成。变更闭包需新候选，不改旧成功回执。
- **入剪闭合**：新 PNG 到镜头到最终帧保留时间线映射；解码成片实际检查章节文字、切点和故障时间码前后连续帧。溶解区按合成关系核对，不拿字节等同替代混合验证。帧数、检查数和阈值按实际剪辑推导；某次的 910 源帧、922 成片帧或 57 处检查不是模板要求。

对丢失新增树变换、漏隐藏一组受限树、错误地图/源帧、旧包变化、未知包等关键门加入拒绝用例。检查器遇到证据缺失应失败，不自动改场景或回填“成功”。交付分别报告原生完成、全片解码、人审和发布；播放器持有精确文件也只证明打开。
