# 交付、人工验收与公开

## 输出完整性

逐帧检查输出索引集合、重复/缺失、文件格式与尺寸、字节和 hash，而不只是目录计数或进程 exit0。实际动画读回应覆盖每个实际渲染输出帧；离线中间帧评估可作为补充，不能替代渲染世界的观测。

编码后检查容器、视频 codec、分辨率、fps、帧数、时长、音轨参数、色彩标签、流式播放布局和完整音画解码；按实际任务定义合理时长误差。封装前后重核输入完整性，绑定最终视频 hash。图片序列齐全不等于编码成功，完整解码成功也不等于画面/听感合格。

## 人工验收要单列

正常速度观看完整视频，检查：路线是否符合已确认方案；主体可读；是否穿帮、突转、晕眩；银行角与视线是否自然；材质、曝光、反射、时序闪烁；动态对象；背景；音画节奏及听感。

AI 无权查看的完整画面必须由人工检查。打开命令、排队预览、静态截图、技术回执都不等于用户已看过。用户说运镜不满意或颜色仍红紫，就保持未通过状态，不称全白、AAA、3A、电影级或全部修好。重新回到新航线/色彩方案确认，不反复渲染被否决方案。

报告可用这些明确状态：`PLAN_PENDING_APPROVAL`、`OFFLINE_CHECKED`、`NATIVE_READBACK_CHECKED`、`NATIVE_FRAMES_VERIFIED_PENDING_HUMAN_REVIEW`、`ENCODED_AND_FULLY_DECODED_PENDING_HUMAN_REVIEW`。名称只是说明层级，不能凭写入标签制造证据。

## 发布边界

本地制作、打开视频、整理 skill、建立公开文字案例，与上传工程、发布视频、推送仓库、购买生成服务是不同授权。只执行用户明确授权的动作。

公开前从干净 staging 制作 allowlist，核查全部文件（含嵌入路径、JSON、图片元数据和 Git 历史）：无账户、邮箱、凭证、私人绝对路径、受限几何/纹理/像素、原生工程与未经授权音视频。不要把私有工作目录的 Git 历史直接改为公开。

为第三方模型、音频、字体、图像逐项核对许可证、来源和署名要求。CC0 标签也需证据；不因“免费”或“下载得到”就纳入包。技能 MIT 授权只覆盖新自有文档与代码，不能替代第三方许可。
